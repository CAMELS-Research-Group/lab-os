Finding 01 · the human signal

The steering vocabulary converged

Jean, Kiara, and Arya wrote their operator conventions independently. All three landed on the same six buckets.

  • Setting the mode
  • Authorizing an action
  • Delegating
  • Being interviewed
  • Keeping it honest
  • Commands & rituals

Three people, one structure, no coordination. That is the argument for adopting it as a shared vocabulary, not a personal habit.

Finding 02 · the engineering signal

The strongest promotes are the convergent ones

Patterns that showed up in two or more sources without either naming the other:

  • Dependency seam · swap by config
  • Soft-degrade by default
  • Mocked tests ≠ live verification
  • Evidence over assertion
  • Done = pushed
  • One writer per tree
  • Fail-fast config guards
  • 4-part status summary · 3 surfaces
Finding 03 · the load-bearing tension

Resilience can hide a broken feature

Soft-degrade keeps the app usable when a dependency dies. It also masks whether the premium path ever worked.

An internal application ran four sprints on a dead provider key and stayed usable the whole time. The premium path was never verified live. Soft-degrade only ships paired with a live-verification harness and a visible "degraded" signal.

Finding 04 · the through-line

Enforce by construction, at authoring time

  • Guards, not sweeps — a write-time PreToolUse guard beats cleanup that recurs forever.
  • Invariant over promise — a surface that never holds a value can't leak it.
  • Rule and helper together — prose-only promotion invites copy-paste drift.

Six internal coordination modules independently re-derived the same file-locking discipline. The lesson: ship it as shared code, not a paragraph to remember.

Where it goes

The recommendation

  • Adopt the six-part steering grammar as a handbook page.
  • Author the convergent promotes first — cross-source agreement is the ranking.
  • Pair every soft-degrade with live verification before it counts as done.
  • Arya's conventions are folded into the collection as of today.
